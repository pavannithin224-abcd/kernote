# Onboarding

Welcome. Your first week:

1. Get access to the repository, the staging database and the Redis dashboard.
2. Read `ARCHITECTURE.md`, then the ADRs in `docs/adr/` in order.
3. Set the project up locally — the steps are in the README, not here, because
   duplicating them means one copy goes stale.
4. Pair on an on-call shift before taking one. The runbooks are in
   `docs/runbooks/`.
5. Ship something small. A console copy change is a fine first deploy.

Ask questions in the team channel rather than guessing. Nobody here minds.
