# ADR-0004: Session cookies, not JWTs

Status: accepted
Date: 2025-05-30

## Context

The console is a first-party browser application on one domain.

## Decision

Server-side sessions in Redis, delivered as a `Secure`, `HttpOnly`,
`SameSite=Lax` cookie.

## Alternatives

- **JWT in localStorage** — rejected; no revocation and an XSS-readable token.
- **JWT in a cookie** — rejected; keeps the revocation problem without
  removing the cookie.

## Consequences

Logout is immediate and real. Sessions are lost if Redis is flushed, which is
acceptable and documented in the runbook.
